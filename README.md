# 观点进化缸 · Opinion Evolution Tank

> **把每一个知乎问题变成一个可观察、可干预、可放生的「观点生态系统」——像生物学家一样围观知乎。**

## 这是什么

知乎表面上是问答社区，实质上是一个**观点的自然选择场**。
一个问题下几十上百个回答在争夺同一种稀缺资源：注意力。
赞同是能量，评论是繁殖，权威是体型，热榜是气候突变。
**留在顶部的高赞回答，不一定是最正确的那个，而是最适应当时生态位的那个物种。**

但知乎只把结果给你——高赞排在最上面。你看不见的是：
它靠的是数据、故事、情绪，还是身份认同？换个问题、换个时间点，它还能不能活？
**我现在写的这条回答，扔进去会怎样？**

观点进化缸把这套看不见的竞争变成一个可以观察、可以调参、可以做实验的生态缸：

| | |
|---|---|
| 🔬 **观察** | 每条回答 = 一个物种。圆面积 = 能量（赞同数），颜色 = 立场，圆内符号 = 生存策略，描边粗细 = 权威等级 |
| ⏱ **回放** | 拖动时间轴，回答按发布时间依次入场，看这个生态是怎么长成现在这样的 |
| 🎛 **干预** | 改变缸的规则（推荐权重 / 情绪气候 / 大 V 加权），生态图实时重算——**同一个问题，换套平台规则，胜出的物种完全不同** |
| 🐟 **放生** | 把你还没发出去的回答扔进缸里，拿到存活预测、压制来源与具体改写建议。**一次零成本的发布预演** |
| 📤 **导出** | 一键生成「观点进化图谱」长图，可直接发回那个问题下形成二次讨论 |

## 两个值得一读的工程决策

### 1. 隐藏接口：文档会过时，额度清单才是能力地图

官方文档里**没有**「问题 ID → 回答列表」接口，这本来是产品的致命缺口。
但免费的 `/api/v1/quota` 返回的 APIID 清单里，出现了一个文档从未提到的
`question_answers`——**有额度项就必然有对应端点**。盲猜路径后，错误信息
`QuestionUrl must be a valid Zhihu question URL` 直接告诉了我们正确的参数名。

该接口不返回赞同数，于是用同题搜索结果做 **LCS ≥ 20 连续汉字**匹配来富化——
搜索摘要其实是围绕查询词偏置的**中段片段**，前缀匹配实测命中率为 0，只有 LCS 可靠。
匹配不上的条目如实标注「按热序近似」，**绝不编造赞同数**。

### 2. 直答是问答产品，不是指令执行器

最初把知乎直答当「输出 JSON 的分类器」用，结果 40 个物种被清一色标成
「中立·数据论证」，可视化成了一坨同色圆点——**而系统毫无察觉**。

排查后发现：直答会无视 system prompt 与格式要求，把输入里的问题当提问来答
（原始响应留证在 `docs/evidence/`）。于是按能力重新分工：

- **逐条标注** → 本地可解释模型（词典 + 句法规则 + 问题类型先验），零 API 额度，
  每个判定带命中证据，界面可展开看「凭什么这么判」
- **整缸解说** → 直答，**自然语言提问不加格式约束**。它自发分出 5 派、
  给出每派说服方式与谁占上风，还标注了检索来源——**质量远超被逼着吐 JSON 的时候**

两条独立路径互相印证。主流程零直答依赖（实测直答仅 2 次/日，评委点两下就没了）。

这次失败还留下一条规则：**任何降级路径都必须有分布健康检查**。
现在标注器会在 ≥80% 物种落进同一类时主动告警——
**让失败变成可见的，比让它优雅地失败更重要。**

## 诚信声明

- 演化时间轴是按发布时间**重演入场过程的推演**，官方 API 只提供当前时点数据，
  界面固定标注「**AI 演化重建 · 非历史记录**」，不代表真实历史赞同曲线
- 放生结果标注「**AI 模拟预测**」，不代表知乎平台真实数据
- 标注置信度低于阈值时界面显示「低置信」角标，**不把不确定伪装成确定**
- 额度耗尽、搜索无结果、赞同数无法匹配，界面都显式说明当前处于哪种降级状态
- 演示模式使用虚构作者名并有醒目徽标，**绝不冒充真实知乎用户内容**
- 原方案中的「折叠回答化石层」「作者粉丝数」「收藏数」因官方 API 确实不提供而**主动移除**
